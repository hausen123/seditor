# seditor

S-expression editor for gauche.
S式を括弧ではなく木として編集するためのTUIエディタです。

```
cargo build --release
sedit foo.scm
```

## 木の書き方

ノードのテキストがリストの先頭、子が残りの要素になる。

```
define              (define (square x)
├── square            (* x x))
│   └── x
└── *
    ├── x
    └── x
```

先頭に置くシンボルが無いリストは、テキストを空のままにする。画面には `◦` と出る。

```
cond                (cond ((< x 2) 1)
├── ◦                     ((> x 2) -1))
│   ├── <
│   │   ├── x
│   │   └── 2
│   └── 1
└── ◦
    ├── >
    │   ├── x
    │   └── 2
    └── -1
```

`'` `` ` `` `,` `,@` `#` `#u8` `#;` `#0=` は、子を1つだけ持つと前置記号として扱われる。

```
'                   '(a b)
└── a
    └── b
```

## キー

Normalモードで始まる。`Esc` で戻る。
挿入モードで`Tab` `Shift-Tab` で階層を変える。

| キー | 動作 |
|---|---|
| `F2` | 木とSchemeの表示を切り替える|
| `h` `j` `k` `l` | 左・下・上・右。`j` `k` は行、`h` `l` はテキスト内 |
| `0` `$` | 行頭・行末 |
| `gg` `G` | 先頭・末尾のノード |
| `i` `a` `I` `A` | 挿入モードへ。その場・1つ右・行頭・行末 |
| `o` `O` | 下・上に空ノードを作って挿入モードへ |
| `x` | 1文字消す |
| `dd` | ノードを消して子を1段持ち上げる。消したぶんはヤンクされる |
| `yy` | ノードをヤンクする |
| `p` `P` | 次の兄弟・手前に貼る |
| `>>` `<<` | 階層を下げる・上げる |
| `u` `Ctrl-r` | 元に戻す・やり直す |
| `Ctrl-f` `Ctrl-b` | 1画面送る・戻す |
| `Ctrl-d` `Ctrl-u` | 半画面送る・戻す |
| `PageDown` `PageUp` | 1画面送る・戻す |

`u` は挿入モードの1セッションをまとめて戻す。`i` から `Esc` までに打ったものが一括で消える。

`h` `j` `k` `l` `x` `dd` `yy` `p` `P` `G` には回数を付けられる。`yy` はノード単位なので、部分木を複製するときは行数を数えて `3yy` のようにする。

tmuxの中では既定のプレフィックスが `Ctrl-b` なので、`Ctrl-b` はアプリに届かない。`PageUp` を使うか、tmuxのプレフィックスを変更する。

## コマンド

| コマンド | 動作 |
|---|---|
| `:w` | 保存する |
| `:w {file}` | 名前を指定して保存し、以降その名前を使う |
| `:e` | 読み直す |
| `:e {file}` | 開く |
| `:q` | 終了する |
| `:q!` `:e!` | 未保存の変更を捨てる |
| `:wq` `:x` | 保存して終了する |
| `:42` | 42行目へ移動する。`:$` で末尾 |
| `:set number` | 行番号を出す。`nu` と略せる |
| `:set nonumber` | 行番号を消す。`number!` で切り替え |

行番号は木の表示ではノードの通し番号で、`5G` の飛び先と一致する。ソース表示では出力の行番号になる。

## 制約

- `;` のコメントは行頭にだけ置ける。式の中にあるファイルを開くと、その式の直前の行に出される。
- 改行位置や空行は保存されない。読み込むと木になり、出力は整形規則で決め直される。
